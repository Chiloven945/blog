# Font licenses

License files for the v2 font stack. Each font is distributed under the SIL Open Font License 1.1
(OFL). The actual font binaries are added in the R2 milestone.

| Font              | Role                     | License file                | Source                                          |
|-------------------|--------------------------|-----------------------------|-------------------------------------------------|
| Source Han Sans   | zh-CN article / UI sans  | `source-han-sans-OFL.txt`   | https://github.com/adobe-fonts/source-han-sans  |
| Source Han Serif  | zh-CN novel body serif   | `source-han-serif-OFL.txt`  | https://github.com/adobe-fonts/source-han-serif |
| Google Sans Flex  | English UI / sans        | `google-sans-flex-OFL.txt`  | https://github.com/googlefonts/googlesans-flex  |
| Libre Baskerville | English novel body serif | `libre-baskerville-OFL.txt` | https://github.com/impallari/Libre-Baskerville  |
| Cascadia Code     | code                     | `cascadia-code-OFL.txt`     | https://github.com/microsoft/cascadia-code      |

Fonts are self-hosted; retain these license files alongside the binaries and keep the copyright
notices intact.
